# Names and quotations in sixteen languages

This file is generated by `scripts/language/build_card_text.py`. Do not edit it by hand: change the
sources and run the script again. It records, for every card, where its name and its quotation in each
language came from, and it lists everything that was translated for the game rather than taken from a
source, and everything that is missing.

English is the source of truth (`src/lib/cards.ts`) and is not repeated in the per-language tables.

## What the words in the "source" columns mean

**Names**

- `wikidata`: the label of the Wikidata item in that language, fetched from the Wikidata API
  (`wbgetentities`). Licence CC0 1.0. A disambiguating bracket at the end of a label ("Portia (The
  Merchant of Venice)") is cut off. Chinese uses the `zh-hans` label, then `zh-cn`, then `zh`. For the
  languages written in Latin letters (es, fr, de, it, pt, pl, vi, id) the item's `mul` label is used when
  the language has no label of its own: Wikidata defines `mul` as the label for every language that has
  none. It is not used for other scripts, where a Latin-letter name would not be a name in that language.
- `wikipedia`: Wikidata has no label, but that language's Wikipedia has an article on the item; its title is used.
- `derived`: cut by a fixed rule from a sourced label. Two rules exist. (1) The card shows one word of a
  longer name ("Brutus" from "Marcus Junius Brutus", "Cassius", "Bottom"): the word in the same position is
  taken when the label in that language has the same number of words, otherwise the whole label is used.
  (2) A title character whose own item has no label in the language takes the name from the title of the
  play in that language ("Hamlet", "Macbeth"; "Romeo" and "Juliet" from the two halves of the title).
- `translated`: the game's own invention (relics, potions, "Lord Montague", "Lady Capulet", houses,
  elements). Written for the game by the language model that did this work. **Not reviewed by a native
  speaker and not checked by an independent tool.**
- `missing`: no source has the name in that language. Nothing was invented: the card shows the English
  name there, and the invocation accepts the English name.

**Quotations**

- `published`: copied by program from a published translation that is in the public domain. The text is the
  span matched in the transcription at the URL given (a permanent link to the revision read). Line breaks
  of verse are shown as " / ", footnote marks are removed, and a leading or trailing dash is cut; nothing
  else is changed. François-Victor Hugo's long dashes inside a line mark the verse lines of the original
  and are his.
- `NEW, unsourced`: no public-domain translation of the line was found in that language (or none was
  searched for; see "What was not done"). The line was translated for the game by the language model that
  did this work. **It is generated text. It has not been reviewed by a native speaker, and it has not been
  checked by a back-translation model or a grammar checker.** Do not present it as a published translation.

The quotations on the mythology cards (OL-, UW-) are not quotations from any work: they are lines written
for the game in English. They can only ever be translated, never sourced.

## How the game uses this

- `src/lib/cards-i18n/<lang>.ts` holds the names, lines, scenes, labels and stop words of one language. It is
  loaded with the interface language (for display) and with a duel's language pack (`loadPack`).
- Signature: in a duel fought in a language that has its own line for the card, the telling words are the
  words of that line that are long enough for the language (`lang.ts`) and are not on the stop list. A word
  is echoed when a verse word begins with it (or with all but its last letter, for words of five letters or
  more), which allows for endings; in Arabic it may sit inside a word; in Chinese, Japanese and Thai words
  are cut by `Intl.Segmenter` and matched on letters. Four words running from the line is a quotation and is
  refused. The English line's words still count, and reciting the English line is still refused.
- Invocation: each word of each character's name in the duel's language counts, with the item's one-word
  aliases, as well as the English names.
- An English duel does not go through any of this.
