# 0008. The English voice's pronunciation from the CMU dictionary, not eSpeak NG

## Context and problem statement

The English voice is Kokoro-82M through kokoro-js 1.2.1 (Apache-2.0). kokoro-js turns text into phonemes (G2P: grapheme to phoneme, how a word is said) with the npm package `phonemizer` 1.2.1, which is labelled Apache-2.0 but embeds a compiled eSpeak NG as base64 WebAssembly. eSpeak NG is GPL-3.0-or-later. The package ships no GPL notice and no source offer (research §3.4, by inspection of the tarball). Serving it to browsers distributes GPL object code without the GPL's conditions. What should the voice use instead?

## Decision drivers

- Fix the licence before the deploy.
- Keep the voice working in English.
- Prefer a source the game already pins (the cmudict commit and sha256 behind the verse rules), even if a second table must be derived from it.

## Considered options

1. Comply: ship the GPL notice and the eSpeak NG source as a separable module.
2. Replace G2P with a permissive one built on the CMU Pronouncing Dictionary. The game ships only a reduction of it (`pron-en.ts`: rhyme keys and syllable counts, generated from a pinned commit with its sha256, BSD-style licence: ADR 0015), so the voice needs a second table of whole pronunciations derived from the same pinned source.
3. Replace G2P with Kitten TTS 2's Apache-licensed G2P (research §3.4: Apache verified, fit not).
4. Drop the voice.

## Decision outcome

Option 2, chosen by the owner. The branch (commits `21446923` and `35f43c22`, 2026-11-19) does it this way:

- `src/lib/voice/lexicon-en.ts`: whole CMU pronunciations with stress, generated by `scripts/build-voice-lexicon.mjs` from the same pinned cmudict commit, sha256 and SCOWL release as `build-pronunciation.mjs` (whose pins are now shared; `pron-en.ts` rebuilds byte for byte).
- `src/lib/voice/nrl-rules.ts`: the letter-to-sound rules of NRL Report 7948 (1976, a US government work), generated from a public-domain 1985 transcription, for words the table lacks.
- `src/lib/voice/g2p-en.ts`: text normalising, the table written in the British symbol set Kokoro v1.0 was trained on, weak forms, heteronyms by context, compound parts and held sounds, then the NRL rules. Misaki's own dictionaries are not used, because nothing records their source.
- `astro.config.mjs` aliases `phonemizer` to a stand-in that throws; `thespian-voice.ts` feeds Kokoro the game's phonemes.
- `scripts/check-no-espeak.mjs`, run by `npm run build`, fails when `dist/` holds phonemizer's glue or eSpeak NG's data. By the commit message it fails on `c22b035a`'s build (Kokoro chunk 2,177,801 bytes) and passes on the branch (857,744 bytes; the table is its own chunk).

### Consequences

- Good: no GPL code shipped; one pinned English pronunciation source, from which two tables are derived (the verse rules' reduction and the voice's whole pronunciations).
- Cost: a second generated table to ship and keep in step; its download size is Not known until the branch is built for deploy.
- Words missing from the dictionary go to the NRL rules. How well that sounds is measured on 200 slang words and names written before any reading was heard (`scripts/voice/slang-and-names.txt`); the result is Not known here.
- Open: the voice model itself, Kokoro-82M (2025-01-27, Apache-2.0), still predates the owner's 2026-04-01 rule; this record does not change that.
- Open: the CMU dictionary is American English; the voice is British (`bm_george`). Whether stress and vowels sound right is for listeners to judge.

### Confirmation

On the branch: the build check above; `tests/voice.spec.ts`, in which the real Kokoro speaks a line through the page and Whisper must hear its words; and 25 planted faults that each turn the voice unit tests red (`scripts/voice/mutate-voice.mjs`). Still Proposed: a person listens to the 200-word list before deploy. The deploy checklist repeats the bundle check (`../17-operations-runbook-and-launch-checklist.md` §8.1).

## Pros and cons of the options

| Option | Pros | Cons |
|---|---|---|
| Comply with GPL | no engineering change | source offer and notices to maintain; GPL code in a page |
| CMU-based G2P | permissive; source already pinned | a second derived table to ship; unknown words; American pronunciations |
| Kitten TTS 2 G2P | Apache; 2026 release | fit with Kokoro unverified |
| No voice | simplest | loses a feature |
